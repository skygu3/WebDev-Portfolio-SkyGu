Accessibility Statement

What Is Web Accessibility?

Web accessibility means designing websites so that people with disabilities can use them effectively. Good accessibility also benefits everyone, including people using small screens or slow connections.

Features on This Site

Language Declaration

Every page has lang="en" on the html tag so screen readers know what language to use.

Descriptive Alt Text

Every image has a meaningful alt attribute. For example: alt="Pedri, my loved FC Barcelona player".

Semantic HTML

This site uses header, nav, and footer instead of plain divs everywhere. This gives screen readers a meaningful structure to navigate.

Heading Hierarchy

Headings go in order: h1 → h2 → h3. Screen readers use headings to let users jump between sections.

Color Contrast

Dark blue text sits on a soft white background (the team photo is faded almost fully into white), which keeps strong contrast. White text is used on dark blue backgrounds such as the nav bar and headers.

Meaningful Link Text

Links use descriptive text like "My GitHub Repositories" rather than "click here". Links also have title attributes for extra context.

Responsive Design

The layout adapts to different screen sizes using media queries. Users on mobile will still see a readable layout.

Read Aloud

Every page has a Read Aloud bar at the bottom. Clicking Read reads the page content out loud using the browser's built-in text-to-speech engine. Users can also choose a playback speed: 0.5x, 1x, 1.5x, or 2x. The bar can be collapsed or reopened with a small arrow so it never blocks the content. This helps users with reading difficulties or visual impairments. I researched this feature online and used AI assistance to implement it, as it goes beyond the JavaScript taught in CS12.

What I Would Improve With More Time

  • Add skip navigation links for keyboard users
  • Test with a real screen reader such as NVDA or VoiceOver
  • Verify contrast ratios meet WCAG AA standard (4.5:1 minimum)
