Design Thinking

My Define Statement

A Grade 12 student needs a way to present their coding skills and personality online so as to build a personal portfolio and share their work with others.

The 5 Stages

1. Empathize

I thought about who would visit my site: classmates, teachers, friends.

2. Define

I needed a clear, readable site that shows my skills without being confusing.

3. Ideate

I sketched different layouts and considered color schemes and page structure.

4. Prototype

I built the site starting with index.html, then CSS, then more pages one at a time.

5. Test

I tested in the browser at every step and used DevTools to fix layout issues.

Design Principles I Applied

Visual Hierarchy

Larger headings draw attention to the most important content. The footer is small and gray so it does not compete with the main content.

Consistency

Every page uses the same nav bar, card style, color scheme, and font. This makes the site feel unified.

Navigability

The nav bar appears at the top of every page. Users can always find their way without using the browser back button.

Color & Typography

I used Arial with Helvetica as fallback for the main text, and a rounded font for the welcome page. Dark blue on the soft white background gives strong contrast. Dark red is used only for hover effects and accents.

Challenging Parts

  • Making the welcome page show only on first load or refresh.
  • Keeping the nav bar consistent across every page.
  • Getting the Read Aloud feature to work with different speeds.
  • Lining up images so they look balanced.

What I Learned

  • How to plan a multi-page site before building it.
  • Keeping HTML, CSS, and JavaScript organized in separate files.
  • Testing in the browser early to catch layout problems.
  • Small design choices make a big difference in how a site feels.

Beyond the Course

Some features go beyond CS12. I researched them online and used AI assistance to add them:

Extra JavaScript

  • Web Speech API for the Read Aloud feature
  • sessionStorage to remember the visitor and reading speed
  • Performance Navigation API to show the welcome page only on first load or refresh

Extra CSS

  • opacity, visibility, transition for fade effects
  • backdrop-filter: blur and rgba() for the blurred overlay
  • linear-gradient + background-attachment: fixed for the site background
