Design Thinking

My Define Statement

A Grade 12 student needs a way to present their coding skills and personality online so as to build a personal portfolio and share their work with others.

The 5 Stages

1. Empathize

I thought about who would visit my site — classmates, teachers, or future employers.

2. Define

I needed a clear, readable site that shows my skills without being confusing.

3. Ideate

I sketched different layouts and considered color schemes and page structure.

4. Prototype

I built the site starting with index.html, then CSS, then more pages one at a time.

5. Test

I tested in the browser at every step and used DevTools to fix layout issues.

Design Principles I Applied

Visual Hierarchy

Larger headings draw attention to the most important content. The footer is small and gray so it does not compete with the main content.

Consistency

Every page uses the same nav bar, card style, color scheme, and font. This makes the site feel unified.

Navigability

The nav bar appears at the top of every page. Users can always find their way without using the browser back button.

Color & Typography

I used Arial with Helvetica as fallback for the main text, and a rounded font for the welcome page. Dark blue on the soft white background gives strong contrast. Dark red is used only for hover effects and accents.

Beyond the Course

Some features on this site go beyond what we learned in CS12. I researched them online and used AI assistance to add them. Here is a quick list of the extra tools I used:

Extra JavaScript

  • var variables to remember the chosen reading speed
  • Web Speech API (speechSynthesis) for the Read Aloud feature
  • The event object and changing element .style to update buttons and pop-ups
  • sessionStorage to remember if the visitor has already entered the site
  • The Performance Navigation API to tell a page refresh apart from clicking Home, so the welcome page only shows on first load or refresh

Extra CSS

  • opacity, visibility and transition for smooth fade in and fade out effects
  • backdrop-filter: blur to blur the background behind the team photo
  • rgba() colors for semi-transparent overlays and borders
  • linear-gradient over a background image to blend the team photo with white for the whole-site background
  • background-attachment: fixed to keep that background still while scrolling
  • letter-spacing to soften the look of the welcome text
